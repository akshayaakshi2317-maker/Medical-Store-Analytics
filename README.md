# Medical Store Management - Data Analytics Project

## Demo
https://medical-store-analytics-dzju6kqw8ftyme4ykmcwjb.streamlit.app/

## 📊 Overview
This project analyzes medical store data to improve medicine stock management, sales tracking, and inventory monitoring.

## 🔧 Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📁 Dataset
The dataset contains:
- Medicine names
- Categories
- Stock availability
- Prices
- Expiry dates
- Suppliers
- Monthly sales

## 📈 Analysis
- Medicine sales analysis
- Low stock detection
- Category-wise stock distribution
- Expiry date analysis
- High selling medicine identification

## 💡 Insights
- Some medicines have very low stock levels
- Fever medicines show higher sales
- Equipment medicines are expensive but less sold
- Certain categories require frequent restocking
